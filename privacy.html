Política de privacidad de VIENA NOC Tools

Edición destinada a Chrome Web Store. Última actualización: 10 de octubre de 2026.

VIENA NOC Tools facilita tareas de operadores autorizados en VIENA, MIRA 5, MOICA2, GPON, Fuentes, Métricas y Grafana. No proporciona acceso a esos sistemas. Contacto de soporte y privacidad: foschi246@gmail.com.

Información utilizada

La extensión almacena preferencias, usuario VIENA y apellido configurado, plantillas, botones, macros y personalizaciones en el almacenamiento de la extensión del navegador. Algunas preferencias pueden sincronizarse mediante Chrome Sync, según la configuración del navegador. Las herramientas leen y modifican el contenido necesario de las páginas corporativas compatibles para las acciones operativas elegidas por el usuario. Este contenido puede incluir información de tickets y clientes disponible en esas páginas.

Registro de instalaciones

La extensión envía por HTTPS a un servicio de registro de Google Apps Script un identificador de instalación, usuario VIENA, versión, build, identificador de extensión, canal, motivo del reporte y fecha. Estos datos permiten identificar la instalación y su estado operativo. El payload de este registro no incluye textos de tickets, nodos, contraseñas, plantillas ni macros. Google presta infraestructura al servicio; las respuestas pueden provenir de dominios de Google asociados a Apps Script.

Uso y comunicación

La información se utiliza para proporcionar las funciones operativas y mantener el registro de instalaciones. No se vende ni se utiliza para publicidad personalizada o decisiones de solvencia crediticia. La extensión no incorpora seguimiento de navegación general. Las acciones en sistemas corporativos se ejecutan con la sesión y permisos que el usuario ya tiene; sus registros y tratamientos de datos están sujetos a las políticas de la organización que administra esos sistemas.

Respaldo y control

El usuario puede exportar un archivo JSON con preferencias e identidad, que puede contener datos operativos creados por él. La exportación se descarga localmente; la herramienta de respaldo no lo envía al registro ni a otro servicio. Debe guardarse en una ubicación privada. La restauración requiere elegir un archivo y confirmar antes de escribir. Los permisos de carpetas y sus handles permanecen en la instalación original y no se exportan.

Migración entre instalaciones

A pedido del usuario, la edición de tienda puede trasladar la configuración desde una instalación manual compatible de VIENA NOC Tools en el mismo perfil de Chrome. Solicita el permiso opcional para identificar instalaciones y desactivar el origen elegido, con confirmación del usuario. La lista de extensiones se utiliza localmente para encontrar el origen y no se envía al registro ni a otro servicio. Las preferencias se transfieren mediante mensajería interna de Chrome; el puente del origen sólo admite solicitudes del ID de tienda kncbbeclddielngolalkmlclfljgaoje. Se guardan datos temporales de recuperación localmente durante el traslado. Después de verificar la copia, se desactiva la instalación original sin desinstalarla ni borrar sus datos. No se trasladan contraseñas, sesiones ni permisos de carpetas. El respaldo manual sigue disponible como alternativa.

Conservación y eliminación

Las preferencias permanecen en el navegador hasta que el usuario las modifique, borre el almacenamiento o desinstale la extensión; la configuración de Chrome Sync puede conservar preferencias sincronizadas. Desinstalar no elimina los reportes del registro externo. Para consultar, corregir o solicitar eliminación de esos reportes, escribir a foschi246@gmail.com; puede ser necesario verificar la identidad y coordinar con el administrador del registro y las obligaciones de la organización. No se establece un plazo automático de eliminación que el servicio no implemente.

Seguridad y cambios

El registro utiliza HTTPS. El almacenamiento y los respaldos dependen también de la seguridad del perfil del navegador y del equipo. No compartir respaldos ni credenciales corporativas. La edición de tienda incluye su código ejecutable y recibe actualizaciones mediante Chrome Web Store. Esta política debe actualizarse si cambia el tratamiento de datos.
